# ai-skills

Private backup of personal AI coding-agent skills (mirrors `~/.config/ai/`).

## Contents

- `Super Ultra Code Plan Implementation.md` — unified pipeline for AI coding agents:
  idea → design → plan → implementation → verification. Merges brainstorming,
  writing-plans, TDD, and verification-before-completion with hard human-approval gates.

## Use

Clone to `~/.config/ai/` (or symlink the files there) so agents can read them as skills.
